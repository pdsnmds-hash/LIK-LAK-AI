# LIK LAK AI Sandbox

English-only Android educational casebook. applicationId: `bg.liklak.sandbox`. minSdk 26, targetSdk 36, compileSdk 37.

The app includes 36 cases, 12 local Kotlin experiments, 110 guides with 503 sections, Python reference recipes, prompt templates, a task-plan builder and an on-device saved library. External references and contact details are copy-only. No cloud AI model runs in the app.

Language controls have been removed from Settings and onboarding. Existing installations load English regardless of their previous language preference. Saved records, IDs and the database schema are preserved; user-authored text is not automatically rewritten.
